为什么选择 ClipFlow？

摒弃臃肿的 Electron 包装，用 Rust 核心与系统原生 WebView 实现全平台极轻体积、闪电响应与优雅体验。

⚡️

Rust + Tauri v2 毫秒级响应

后端由 Rust 原生驱动，前端采用 React + Tailwind CSS 渲染于系统内置 WebView，告别 Electron 笨重内存开销，跨端依旧极速丝滑。

⌨️

系统级全局热键

基于系统原生热键接口注册，跨平台支持 ⌥/Alt + V 与 ⌘/Ctrl + ⇧ + V。无需记录击键输入，任何桌面场景下始终秒级响应。

🛡️

密码管理器防泄密

同时遵守 macOS ConcealedType 与 Windows ExcludeClipboardContentFromMonitorProcessing 隐私标记，并自动过滤 1Password、Bitwarden、KeePassXC 等密码软件。

常见问题与解答

解答您对跨平台支持、系统权限与隐私安全的疑问。

Q1: 为什么 ClipFlow 不需要「输入监控 (Input Monitoring)」权限？

市面上许多剪切板工具通过全局键盘 Hook 监听按键，需要用户授予危险的“记录所有击键输入”权限。ClipFlow 通过 Tauri 全局快捷键插件直接调用各操作系统原生的热键注册接口，免去了敏感的击键监听权限，也不会被前台应用程序轻易拦截。

Q2: macOS 下为什么需要「辅助功能 (Accessibility)」权限？Windows / Linux 需要吗？

当您在列表中双击或按下回车时，ClipFlow 需要将焦点自动交还给您刚才正在工作的软件，并向该前台窗口模拟发送一次粘贴组合键（macOS 为 Cmd + V，Windows / Linux 为 Ctrl + V）。macOS 端仅该自动化粘贴步骤需要辅助功能权限；Windows 端通过原生 SendInput 开箱即用；Linux (X11) 端仅需确保系统已安装 xdotool。

Q3: 复制 1Password / Bitwarden / KeePassXC 密码时会泄露吗？

绝对不会。ClipFlow 在 Rust 监听循环中深度集成了隐私过滤规则，同时遵守 macOS 的 org.nspasteboard.ConcealedType / AutoGeneratedType 与 Windows 的 ExcludeClipboardContentFromMonitorProcessing 规范，并识别常见密码管理器来源，所有受保护口令均被静默跳过。

Q4: 如何开启或关闭开机自启动？

右键点击系统托盘（macOS 顶部菜单栏 / Windows 右下角托盘 / Linux 状态栏）中的 ClipFlow 图标，在弹出的菜单中直接勾选或取消「开机自动启动」即可，底层基于 Tauri 原生 autostart 插件实现。
