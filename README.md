# ClipFlow 📋

现代、轻量、键盘友好的跨平台剪切板管理工具（支持 **macOS / Windows / Linux**）。基于 **Rust + Tauri v2 + React + TypeScript + Tailwind CSS** 构建，体积极小，毫秒级响应。

🌐 **产品官网**：[https://anmingxing.github.io/clip-flow/](https://anmingxing.github.io/clip-flow/)

---

## 🌟 核心特性

- **跨平台且极致轻量**：核心监听、存储与系统交互全部使用 Rust 原生实现，UI 基于 Tauri v2 系统原生 WebView，无 Electron 笨重开销。
- **全键盘驱动交互**：
  - `↑` / `↓`（或 `Ctrl+P` / `Ctrl+N`、`⌘/Ctrl+K` / `⌘/Ctrl+J`）：在剪切板列表中移动选择。
  - `⏎ (Enter)`：自动回切焦点并模拟粘贴（macOS 为 `Cmd+V`，Windows/Linux 为 `Ctrl+V`）到上一个活跃应用。
  - `⇧ + ⏎ (Shift + Enter)`：剥离格式，作为纯文本粘贴。
  - `⌘/Ctrl + 1` ~ `9`：快速粘贴对应序号的剪切项。
  - `⌘/Ctrl + P`：置顶 / 取消置顶选中的项。
  - `⌘/Ctrl + ⌫ (Backspace)`：删除当前选中的历史项。
  - `Tab` / `⇧ + Tab`：循环切换顶部分类标签。
  - `Esc`：优先清空搜索词，搜索框为空时关闭悬浮窗。
- **多类型内容识别与深度预览**：
  - 纯文本 / 代码（自动检测并格式化合法 JSON）
  - 网址识别（提取 `http/https` 链接并在默认浏览器一键打开）
  - 富文本 / RTF
  - 图片（PNG 本地独立附件缓存与缩略图预览）
  - 文件 / 文件夹（支持文件 URL 列表）
  - 颜色（自动匹配 `#RGB`, `#RRGGBB`, `#RRGGBBAA`, `rgb()`, `rgba()` 并展示色卡及 HEX/RGB 一键复制）
- **隐私与安全保护**：
  - 自动识别并过滤 1Password、Bitwarden、KeePassXC 等密码管理器。
  - 遵守系统私密标记（macOS `org.nspasteboard.ConcealedType` / `AutoGeneratedType` / `TransientType`，Windows `ExcludeClipboardContentFromMonitorProcessing`），杜绝密码泄露。
  - 所有数据仅存储在本地应用数据目录（macOS `~/Library/Application Support/clip-flow/`、Windows `%APPDATA%\clip-flow\`、Linux `~/.local/share/clip-flow/`），绝不联网。
- **智能排重与清理**：
  - 基于 SHA-256 哈希排重，重复复制自动刷新时间戳并前移，最高保留 1000 条非置顶历史。
  - 支持固定置顶项，一键清空未置顶历史。
- **系统托盘与全局热键**：
  - 常驻系统托盘（macOS 启用 Accessory 模式隐藏 Dock 图标）。
  - 左键点击托盘图标切换悬浮窗，右键展示统计信息、清理、权限状态与开机自启开关。
  - 全局快捷键 `⌘/Ctrl + Shift + V` 或 `Option/Alt + V` 随时随地唤起。

## 🚀 开发与构建

### 环境依赖
- **Node.js** >= 18 & **npm**
- **Rust** stable 工具链 (`rustc` / `cargo`)
- **Linux 额外依赖**：构建需要 `libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf`；运行期自动粘贴依赖 `xdotool`。

### 1. 安装前端依赖
```bash
npm install
```

### 2. 启动开发环境
```bash
npm run tauri dev
```

### 3. 运行测试与编译检查
```bash
npm run build
cd src-tauri && cargo test
```

### 4. 构建发布包
```bash
npm run tauri build
# 或使用打包脚本：
./scripts/build_app.sh
```

## 🔒 权限说明

- **macOS**：自动模拟 `Cmd + V` 粘贴需要系统**辅助功能（Accessibility）**权限。若未授权，可在应用顶部提示横幅点击“去授权”，或在 `系统设置 -> 隐私与安全性 -> 辅助功能` 中开启。
- **Linux (X11)**：自动模拟 `Ctrl + V` 需要系统安装 `xdotool`。
